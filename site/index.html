Terminal dashboard for coding agents

All your coding agents.
One terminal.

See which one needs you. Jump in, jump back out. Works with 18 coding harnesses and plain shell jobs.

Why

Five agents means five terminal tabs, and the one waiting on you is in the tab you aren't looking at. agentview lists every session from every harness in one place, with the ones that need you on top. Selecting a row opens the harness's own interface.

Features
Grouped by statusWaiting for input, working, completed. The harness is shown on every row.
Jump in and back outOpen a native session while its work keeps running, then return to the list.
Bring back any past sessionCtrl+G searches older sessions by name, harness, folder, or ID. No cd or --resume.
Start in any folder/cd or Ctrl+O. Multi-line tasks, pastes, and clipboard images stay one draft.
Migrate a conversationMove a session to another harness with /migrate, or to another folder with Ctrl+M, via session-migrate.
Pause what you're waiting onCtrl+T moves a session into a collapsed Paused group.
